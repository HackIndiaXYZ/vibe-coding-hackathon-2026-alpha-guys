## Suggested GitHub Release Notes (v1.0.0)

```
## 🎓 Smart Semester AI v1.0.0

### First release — HackIndia Vibe Coding Hackathon 2026

### What's included
- ✅ Dashboard with AI daily insight (Claude API)
- ✅ Course management with GPA calculator
- ✅ Assignment tracker (filter, sort, priority, overdue detection)
- ✅ AI Study Assistant (context-aware, full chat history)
- ✅ AI Study Planner (Claude generates weekly schedule as JSON)
- ✅ Notes AI (summarize, key points, flashcards, MCQ quiz)
- ✅ Attendance tracker with at-risk warnings
- ✅ Analytics (4 Recharts charts + performance insights)
- ✅ Settings with data management
- ✅ First-time onboarding wizard
- ✅ Fully offline for non-AI features (localStorage)
- ✅ Dark theme design system (CSS variables)

### Tech stack
React 18 · Vite 5 · Tailwind CSS · Claude Sonnet 4 · Recharts · Lucide React

### Setup
1. `npm install`
2. Copy `.env.example` → `.env` and add your Anthropic API key
3. `npm run dev`
```
